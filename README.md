## Основные функции

- Отображение списка счётчиков в табличном виде
- Фиксированный заголовок таблицы при скролле
- Пагинация с навигацией по страницам
- Удаление счётчиков (по наведению появляется кнопка удаления)
- Автоматическая загрузка адресов для областей
- Типизация счётчиков (ХВС/ГВС) с иконками

## API

Приложение использует API для получения данных о счётчиках и адресах:

- `GET /meters?offset={offset}&limit={limit}` — получение списка счётчиков
- `DELETE /meters/{id}` — удаление счётчика
- `GET /areas?id__in={ids}` — получение адресов областей
